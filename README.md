# Basic Linux System Administration using CentOS

## Project Overview
This project demonstrates basic Linux system administration tasks in a CentOS virtual machine environment.

## Technologies Used
- CentOS
- VMware Workstation Pro
- SSH

## Key Tasks Performed
- Installed CentOS in a virtual machine
- Practiced Linux commands
- Performed user and file management
- Configured basic networking commands
- Installed packages and services
- Configured remote access using SSH

## Skills Demonstrated
- Linux Administration Basics
- Command Line Operations
- User Management
- Networking
- SSH
- Package Management
