# Basic Azure Cloud Infrastructure Setup

## Project Overview
This project demonstrates basic cloud infrastructure setup and administration using Microsoft Azure.

## Technologies Used
- Microsoft Azure
- Azure Virtual Machines
- Resource Groups
- Virtual Networks (VNet)
- Network Security Groups (NSG)
- Microsoft Entra ID
- RDP
- SSH

## Key Tasks Performed
- Created and configured Azure Virtual Machines
- Managed Resource Groups for cloud resources
- Configured Virtual Networks (VNet) and NSG for secure connectivity
- Practiced user access management using Microsoft Entra ID
- Configured remote administration using RDP and SSH

## Skills Demonstrated
- Cloud Infrastructure Basics
- Azure Administration
- Network Security
- Virtual Machine Management
- Identity and Access Management (IAM)
- Remote Administration
